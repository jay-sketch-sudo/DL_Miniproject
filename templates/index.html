CNN-LSTM Encoder-Decoder Architecture

How Computer Vision merges with Natural Language Processing

1 Vision Encoder (CNN)

Pretrained InceptionV3

The image is resized to (299×299×3) and passed through InceptionV3 pretrained on ImageNet. The final classification head is truncated, and global average pooling produces a dense 2,048-dimensional visual feature vector.

2 Feature Fusion

Multimodal Merge Layer

The visual feature is projected into a 256-dim embedding. Concurrently, the partial sentence sequence is embedded and processed through an LSTM layer (256 units). The visual context and textual state are fused via element-wise addition.

3 Language Decoder (LSTM)

Autoregressive Generation

A Dense Softmax layer outputs the probability distribution across vocabulary words. The model emits words autoregressively step-by-step from <startseq> until emitting <endseq> or reaching max length.
